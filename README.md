# SimpleConway - Conway's Game of Life Sequencer
VST3 and Windows Standalone Version.

This project is a preliminary version of ConwayMatrix written with the [HISE Open Source Toolkit](https://hise.dev/).
You will need [HISE](https://github.com/christophhart/HISE) to build this project. 
[A tutorial is available on YouTube](https://www.youtube.com/watch?v=Cp8DpAO5018&list=PLynv7CujPCfYBMVWoaQH3v3ghmVxa4v4B&index=25&pp=iAQB).

Visit [ConwayMatrix site](http://hujackus.altervista.org/conwaymatrix/) for more information on the entire project.
